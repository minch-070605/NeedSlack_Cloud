# NeedSlack Cloud — 작업 규칙

이 프로젝트를 진행하며 지킨 규칙이다. 규칙이 코드·문서와 어긋나면 **규칙이 먼저다.**
진행 상태는 여기에 적지 않는다 — [`docs/개발기록.md`](개발기록.md) 한 곳에만 둔다.

---

## 1. 포지셔닝 — 어기면 프로젝트가 무너지는 규칙

**이 프로젝트에는 실험이 하나뿐이다.** 주 실험은 rev.9 하드웨어의 동적 vs 정적 대조이고,
클라우드는 **그 대조를 파이프라인에 통과시켜 보이는 계측 장치**다.

- ❌ **클라우드에 새 대조축·새 연구 질문을 만들지 않는다.** 두 번째 질문을 열면 둘 다 얕아진다.
- ✅ **`STA_B` 와 `DYN_B` 두 팔을 항상 함께** 통과시킨다. 한 팔만 태우면 대조가 사라져
  "데이터 파이프라인을 만들었다"가 된다.
- ✅ 두 팔에 **동일 레시피·동일 시드·동일 held-out** 을 준다. 경로 차이 0.
- ❌ **범위 밖 항목**(OTA 되먹임·폐루프 수렴성·대조 함대·라벨 예산 실험)을 슬며시 들이지
  않는다. 필요하면 먼저 범위를 바꾸자고 **제안하고 승인받는다.**

---

## 2. 수치 — 하드코딩 금지

- **모든 상수는 `schema/edge_contract.json` 에서 읽는다.** 코드·문서·프롬프트 어디에도
  `1_000_000`, `144_500`, `13.62`, `6.13 GB` 를 직접 쓰지 않는다.
- 계약이 바뀌면 문서를 고치는 게 아니라 **생성기를 다시 돌린다**:
  ```bash
  python schema/gen_edge_contract.py      # rev.9/config.py 를 실행해 재생성 + 자기검증
  python docs/build_artifact.py arch      # 보고서 웹 렌더링 재생성
  python docs/build_artifact.py brief     # 브리핑 웹 렌더링 재생성
  ```
- **생성물을 손으로 고치지 않는다** — `edge_contract.json`, `*.html`. 고쳐도 다음 실행에
  덮어써진다. 고칠 곳은 생성기이거나 원본 `.md` 다.
- 새 파생 수치를 만들면 **식과 출처를 함께** 적는다. 보고서 부록 "파라미터 원장" 형식.

## 3. 문서

- **폐기된 내용은 지우고 새 내용으로 교체한다.** "이전 안은 X였으나 폐기" 를 남기지 않는다.
  문서를 읽으면 **현재 상태가 모호하지 않아야** 한다.
  *(rev.9 에서 폐기 기록을 현재 상태로 착각해 잘못된 결론을 낸 사고가 반복됐다.)*
- **기각한 대안을 같은 문서에 두지 않는다.** 결정문은 결정만 담는다.
- 범위 밖으로 민 것은 이력이 아니라 **"향후 연구"로 간결하게 한 번만** 적는다.
- 완료된 할 일은 목록에서 **덜어낸다.** 체크 표시로 남기지 않는다.
- 설계 결정은 `docs/설계결정-NNNN-<주제>.md` 로 남긴다. 담는 것은
  **맥락 · 결정 · 근거 · 귀결 · 되짚을 조건** 다섯 가지.

## 4. 의존성과 비용

- **새 의존성을 추가하기 전에 묻는다.** 라이브러리·컨테이너 이미지·외부 서비스 전부 해당.
  묻는 내용: 무엇을 대체하는가 · 없으면 무엇이 안 되는가 · 유지비는.
- **범위는 $0 이다.** 과금이 발생하는 AWS 서비스를 도입하기 전에 **반드시 묻는다.**
  현재 제외: Fargate · Athena/Glue · SageMaker 학습 · Aurora.
- **로컬 우선.** MinIO=S3 · DynamoDB Local=DynamoDB · PostgreSQL=Aurora ·
  Mosquitto=IoT Core · DuckDB=Athena · Colab=SageMaker.
  전부 같은 API 를 쓰므로 `boto3(endpoint_url=...)` 하나로 클라우드에 올라간다 —
  **같은 기능을 두 번 구현하지 않는다.**
- AWS 프리티어 한도를 **설계 근거로 삼지 않는다.** 계정 유형·리전마다 다르다.
  한도는 점검 대상이지 전제가 아니다.

## 5. 코드와 커밋

- **기능 단위로 커밋한다.** 한 커밋 = 되돌릴 수 있는 한 가지 변경.
  문서 수정과 코드 수정을 한 커밋에 섞지 않는다.
- 커밋 메시지는 **무엇을 왜** 바꿨는지 적는다. "fix", "update" 금지.
- 저장소는 `main` 브랜치 하나. `.gitignore` 와 `.gitattributes`(LF 고정)가 이미 있다.
- `.gitignore` 가 막는 것: `__pycache__/` · `.env` · 로컬 볼륨(`data/`,`minio/`,`pgdata/`) ·
  재생 입력(`*.bin`,`*.npy`) · 렌더링 산출물(`*.html`). **rev.9 자산을 복사해 오지 않는다.**
- **비밀값을 커밋하지 않는다.** AWS 자격·인증서·토큰은 `.env` 로, 예시는 `.env.example` 로.

## 6. 되돌릴 수 없는 작업

**다음은 반드시 확인받고 실행한다:**

- 파일·디렉터리 **삭제** (특히 `rev.9/` 하위 어느 것도)
- DB **마이그레이션** — 되돌리는 마이그레이션을 **함께** 만든다
- S3/MinIO **수명주기 정책**, 객체 일괄 삭제
- **OTA 배포** — canary → 단계 확대 → 자동 중단 기준이 함께 있어야 한다
- DynamoDB **키 스키마 변경** — 사실상 전체 재색인

> 지시에 *"이 작업의 롤백 경로도 같이 제시해줘"* 를 붙이는 것이 가장 값싼 보험이다.

## 7. rev.9 경계

- **`rev.9/` 는 동결이다. 읽기만 한다.** 논문·경진대회 산출물이다.
- **`rev.9/Teammate/` 를 삭제하지 않는다.** 유일한 보드 실측 증거이고 팀원 작업물이다.
- rev.9 를 **import 하지 않는다.** 계약은 `schema/edge_contract.json` 스냅샷으로만 쓴다.
- rev.9 의 산출물을 읽는 것은 괜찮다 — `selections_axis2/*.npy`,
  `05_데이터셋/board/frames.bin`, `07_RTL/tb/vectors/*.txt`.

## 8. 정직성

- **확인되지 않은 것을 추측해서 쓰지 않는다.** 파일에서 확인 안 되면 "없다"고 말하고
  근거 경로를 밝힌다. *(설계 문서만 있는데 "이 프로젝트는 FastAPI 를 쓴다"고 쓰면
  이후 모든 지시가 틀어진다.)*
- **측정값과 가정을 구분해 표기한다.** 실측 · 유도 · 가정 · 추정 중 무엇인지 적는다.
- **대조군에는 언제나 최선의 전략을 준다.** rev.9 에서 상속한 규율. 그래야 보고하는
  이득이 하한이 된다.
- 결과가 기대와 다르면 **그것이 결과다.** 재현 실패도 발견이다.
